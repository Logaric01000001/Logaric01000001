# Building tools. Understanding systems.

I'm **Logaric**, a developer and security learner working with Linux, Python, JavaScript and Bash. I build practical tools, document how they work, and make their limits visible.

[Explore the portfolio](https://logaric01000001.github.io/Portafolio/) · [Español](README.es.md) · [Technical notes](notes/README.md)

## Selected work

### [Antena ↗](https://github.com/Logaric01000001/antena-arch)
Wi-Fi adapter diagnostics and guided setup for Arch Linux. GTK4/libadwaita interface, a CLI, and a separate privileged helper. The repository includes application screenshots and simulated tests; hardware coverage is limited and documented.

**Python / GTK4 / NetworkManager** — [Screenshots & support limits](https://github.com/Logaric01000001/antena-arch#screenshots)

### [MyDotfiles ↗](https://github.com/Logaric01000001/MyDotfiles)
An Arch Linux workspace built around Niri, Noctalia, Kitty and Zsh, with shell utilities and configuration files. A personal setup to inspect and adapt, with installation effects documented.

**Linux / Wayland / Bash** — [Explore the configuration](https://github.com/Logaric01000001/MyDotfiles#whats-inside)

### [EM ↗](https://github.com/Logaric01000001/EM)
An Express prototype that receives emergency-admission events, checks JSON policy records and builds two notification payloads. A learning project with explicit deployment limitations.

**JavaScript / Express / Webhooks** — [Run locally](https://github.com/Logaric01000001/EM#run-locally)

## How I work

- Start with a real problem and a small, inspectable implementation.
- Separate implemented behavior from hardware verification and future work.
- Learn security through authorized labs, code review and careful documentation.

## Build with me

Useful bug reports, documentation fixes and reproducible hardware observations are welcome. Start with a project's contribution guide or open an issue describing what you tried and what happened. Please remove credentials and personal information from logs.

For project collaboration, use the relevant public repository's Issues. English and Spanish are welcome.
