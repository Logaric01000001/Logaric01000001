Desarrollo herramientas prácticas con Linux, Python, JavaScript y Bash mientras profundizo en desarrollo de software y ciberseguridad. Documento cómo funcionan los proyectos y qué falta por verificar.

- **[MyDotfiles](https://github.com/Logaric01000001/MyDotfiles):** mi entorno Arch con Niri, Noctalia, Kitty y Zsh. Revisa el instalador y sus efectos antes de ejecutarlo.
- **[EM](https://github.com/Logaric01000001/EM):** prototipo Express de eventos de admisión y notificaciones. Es un proyecto de aprendizaje, sin autenticación y no apto para datos reales.
