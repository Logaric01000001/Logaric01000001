# Logaric visual identity

Graphite `#101214`, warm white `#F2EEE7`, amber `#F2B85B`. Use restrained typography, generous spacing and a prompt/bracket motif. Avoid decorative statistics, skill percentages and generic hacker imagery.

The banner is an image generated for this identity with the built-in image tool. Prompt: wide 3:1 graphite editorial technology banner; warm-white “Logaric”; amber prompt mark; “LINUX / SOFTWARE / SECURITY”; subtle drafting grid and a matte folded bracket; no people, skulls, badges or invented metrics.

Keep important copy as selectable text outside images. Portfolio body fonts use the system sans-serif stack; labels use the system monospace stack. No third-party font or analytics service is required.
